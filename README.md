# SQL & API Quiz

Статический квиз для чтения SQL и API-контрактов. Без сборки и зависимостей.
Двенадцать направлений — SQL, API, ERD (ER-диаграммы), BPMN (диаграммы процессов), Use Case (диаграммы вариантов использования), Sequence (диаграммы последовательности), State (диаграммы состояний), Activity (диаграммы активности), Class (диаграммы классов), Component (диаграммы компонентов), System Design (архитектура систем) и Kafka (брокеры, топики и партиции, консьюмер-группы, репликация, доставка, транзакции), в каждом три уровня (базовый / средний / продвинутый). Вопросы каждого направления лежат в своём файле `data/<направление>.js` и подгружаются при выборе направления; список файлов и число вопросов — в `questions.js`. Направление определяется полем `topic`.

## Локально
    npx serve .        # или просто открыть index.html

## Деплой на Vercel
Вариант 1 (CLI): в папке проекта `npx vercel --prod` (Framework Preset: Other, build command пустой).
Вариант 2 (Git): запушить в GitHub → Vercel → Add New Project → Import → Deploy.

## Добавить вопрос
В файл направления (`data/sql.js`, `data/api.js` и т. д.) добавь объект в нужный уровень (`window.QUESTIONS.basic.push(...)` и т. п.), а в `questions.js` обнови число в `TRACK_COUNTS`:
    { topic: "SQL", lang: "sql", q: "...", code: `...`, options: ["верный?", "...", "..."], answer: 0, explain: "..." }
`answer` — индекс верного варианта в `options`; порядок вариантов перемешивается автоматически.

## Добавить ERD-вопрос
Схемы лежат в `window.ERDS` (`data/<направление>.js`): таблицы с позицией `col`/`row` в сетке и связи `[родитель, потомок, метка, метка]`.
В вопросе указывают `topic: "ERD", erd: "shop"` — диаграмма нарисуется над вариантами ответа.

## Добавить BPMN-вопрос

В вопросе указывают `topic: "BPMN", bpmn: "shop_order"` — диаграмма нарисуется над вариантами ответа.

## Добавить Class-вопрос

где вид — `assoc`, `assocd`, `agg`, `comp` (ромб у «от»), `inherit`, `realize`, `dep` (стрелка к «к»).
В вопросе указывают `topic: "CLS", cls: "shop"` — диаграмма нарисуется над вариантами ответа.

## Добавить Component-вопрос

## Добавить System Design-вопрос
Схемы лежат в `window.SDS` (`data/sd.js`) в том же формате, что и диаграммы компонентов, плюс форма узла `shape`: `client`, `lb`, `cache`, `db`, `queue`, `cdn`, `ext`.
Виды связей: `flow` (сплошная стрелка), `async` (пунктир), `bi` (двусторонняя), `dep` (зависимость).
В вопросе указывают `topic: "SD", sd: "web_basic"` — диаграмма нарисуется над вариантами ответа.
